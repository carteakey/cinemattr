# Discover north-star prompt

Create a high-fidelity visual reference for the desktop Discover page of “cinemattr,” a natural-language movie search and discovery application.

Use the homepage north-star direction as the mood reference: repertory cinema projection booth, tactile film archive, warm mysterious mischievous physical artifact. Create a fresh Discover composition rather than copying the homepage.

## Goal

Make Discover feel like a physical card deck assembled inside a repertory cinema projection booth and film archive.

It should feel:

- cinematic
- tactile
- imperfect
- opinionated
- warm
- mysterious
- mischievous
- culturally specific

It must not resemble a SaaS landing page.

## Canvas And Cropping

Create a complete, uncropped 16:10 landscape desktop Discover page.

Reserve a quiet 5% safe border around all four sides.

Every word, navigation item, ticket, film frame, button, movie card, and decorative object must remain completely inside that safe border.

Nothing may touch or extend beyond the canvas.

Do not leave a blank, black, unfinished, or missing region anywhere in the composition.

## Product Hierarchy

Movie discovery is the primary product on this page.

Arrange the page as follows:

Left side:

- cinemattr masthead
- active Discover navigation
- “MOVIE MATCH” label
- large expressive heading
- mood prompt input
- ticket-shaped Deal button
- small keyboard/pass/save hints

Center:

- large tactile movie-card deck
- active card with poster, title, year, genre, rating, and plot snippet
- two or three offset cards behind it
- large Pass and Save ticket controls

Right side:

- saved shortlist rail
- deck status / reel counter
- small film-lab annotations

Bottom:

- compact strip of suggested saved/queued movie cards

The active deck card and Pass/Save controls must be the first interaction users notice.

## Typography

Use an original battered old-style serif for expressive headings.

Combine this with:

- narrow projection-booth labels
- monospaced typewriter copy
- grease-pencil handwriting
- rubber-stamped numbers
- tiny film-laboratory annotations

Avoid clean, smooth, generic digital typography.

## Physical Film Details

Add layered but intentional cinematic artifacts:

- 35mm film strips
- sprocket holes
- amber frame numbering
- red film-edge codes
- vintage color-negative film canisters
- generic reel-box labels
- loose curled film
- leader countdown marks
- projection cue dots
- contact-sheet proof frames
- cinema admission tickets
- balcony tickets
- perforated ticket edges
- torn masking tape
- china-marker arrows
- grease-pencil circles
- rubber date stamps
- fingerprints
- crop marks
- clapperboard fragments
- dust
- hairline scratches
- ink smears
- imperfect crimson and mustard overprinting
- worn bone-colored paper
- rough deckled edges

Use generic vintage film-stock language. Do not feature a prominent modern trademark or logo.

## Discover Card

The active card should show:

- title: “In the Mood for Love”
- year: “2000”
- genre: “Romance / Drama”
- rating: “8.1”
- plot snippet: “Neighbors in 1960s Hong Kong orbit love, restraint, and suspicion.”
- deck counter: “REEL 7 OF 12”

Use real-feeling but implementation-plausible movie imagery. Do not depict recognizable actors or modern brand logos.

Show a right-side local shortlist with:

Show a bottom row of suggested save cards, such as:

- “The Handmaiden”

- “Perfect Days”

## Exact Interface Text

Include:

- “cinemattr”
- “Discover”
- “FAQ”
- “MOVIE MATCH”
- “What should we watch?”
- “Describe the mood, plot, or genre”
- “surprising, highly rated movies with memorable plots”
- “DEAL”
- “PASS”
- “SAVE”
- “SHORTLIST”
- “3 SAVED”
- “SHUFFLING THE DECK”
- “SEARCH BY FEELING, NOT FILTERS”

## Truthfulness

Do not write:

- “curated by humans”
- “not algorithms”
- “hand picked”
- any statement implying humans manually selected the search results

The product uses AI-assisted semantic search.

“SEARCH BY FEELING, NOT FILTERS” is the preferred truthful supporting line.

## Implementation Realism

The design should look distinctive but remain plausible to implement using:

- semantic HTML
- CSS
- existing movie poster images
- lightweight texture overlays
- responsive layouts

Maintain accessible contrast and legible navigation.

## Avoid

- cropped content
- clipped letters
- elements extending outside the canvas
- empty or black lower sections
- SaaS styling
- glassmorphism
- gradient blobs
- rounded dashboard cards
- corporate startup aesthetics
- pricing-page patterns
- glossy neon cyberpunk
- generic stock photography
- browser chrome
- device frames
- modern brand logos
- watermarks
